# 模型图鉴 · Model Atlas

一个用于跟踪 AI 更新、查找案例和课程、核对模型福利的独立站点。前端使用原生 Web 组件，服务端通过 Cloudflare Worker 和 D1 服务 Sites。

**站点** [model-atlas.tarokiki.chatgpt.site](https://model-atlas.tarokiki.chatgpt.site)

| 入口 | 可用功能 |
| --- | --- |
| 案例库 | 原创练习、按模型、分类、来源和时段筛选、双语 Prompt、本地收藏夹、Skills 下载、复测记录 |
| 资讯雷达 | 官方 RSS/Atom 采集、增量去重、故事聚合、精选与全量、来源健康、按新闻提及的实体跳转图谱 |
| 热点图谱 | 2D 关系网络、WebGL 3D 地形、新闻共现和实体检索 |
| 实践课程 | 学习路径、关联案例与 Skills、版本化 Markdown、全文检索、阅读目录、可保存的实践清单 |
| 算力海洋 | Canvas 字符场景、鼠标扰动、点击投喂与福利跳转 |
| 福利卡册 | 官方来源、筛选、手动记录、卡面等级、IndexedDB 备份导入导出 |

## 本地运行

需要 Node.js 24 或更高版本。运行 `npm run dev` 构建并启动开发服务器。本地数据保存在 SQLite，路径可通过 `ATLAS_SQLITE_PATH` 指定。运行 `npm run build && npm run check` 验证构建与核心数据链路。

## 托管与数据

Sites 构建产物是 `dist/server/index.js`。托管迁移在 `drizzle/`，运行时使用 `DB` 绑定。部署时设定管理员账号 `ATLAS_ADMIN_EMAIL`，后台使用 Sites 认证提供的身份。第三方源仅通过服务器上的域名白名单访问。管理员可以新增或暂停白名单内的信源、立即采集、审核投稿，以及登记经核验的互动快照和独立复测。

站点可通过定时请求触发更新，访客请求也可在 30 分钟冷却期结束后触发更新。单源失败保留上次成功快照并退避重试。福利源每天在北京时间 09:00 后首次更新时核验一次。采集只保留新闻标题、来源和时间，课程和案例练习由本站编写。福利记录由用户手动标注，和外部账户、余额与付款完全独立。

`/connect` 提供 REST、RSS 和 Skills 入口。缺少互动或复测证据的案例以空值表示，新闻热度仅来自成功入库的文章。独立复测须提供真实证据，稳定度仅计算已完成人工判定的评审分。
